## 2. 프로젝트 목적과 결과물

Ingrid는 교사가 학교 수업 및 평가 활동을 만들고 학생을 배정한 뒤, 학생의 답안과 수업노트를 수집·관리하고 AI로 분석·피드백할 수 있도록 개발된 웹·모바일 통합 서비스다.

주요 결과물은 다음과 같다.

- 교사·학생·대표교사·관리자 계정과 권한별 대시보드
- 교과 논술형 평가, 교과 수업활동, 행사·자율·동아리·진로활동 관리
- 학생 답안 작성, 자동저장, 제출본 및 수정 이력 관리
- 생성형 AI를 이용한 답안 분석, 채점 보조, 첨삭 및 피드백 생성
- PDF·DOCX·XLSX·이미지 첨부자료의 텍스트 추출과 OCR 기반 분석 문맥 구성
- 촬영 문서의 OpenCV 보정, Google Vision/OpenAI OCR, 원문·교정문 검수 흐름
- 교과 수업노트의 단원 구조, 교재, 페이지 이미지, OCR 결과, 포스트잇 관리
- 시험 감독용 Android 앱과 화면 캡처·전송·재생·보관기간 관리
- 서버 배포·재시작, Android APK 서명·배포 및 최소 지원 버전 관리

## 4. 기술 구성과 구현 범위

### 백엔드·데이터

- Python 3.8 및 Django 4.2 LTS 기반 서버 애플리케이션
- MySQL 데이터베이스와 Django ORM을 이용한 사용자, 활동, 답안, 분석결과, 감독기록, 수업노트 데이터 모델링
- 역할 기반 접근제어와 학교·교사·학생 단위 데이터 범위 제한
- 답안 초안·제출본·AI 피드백 세션의 버전 및 상태 관리
- Excel·Word·PDF 내보내기와 대량 학생 데이터 처리

### AI·문서 인식

- OpenAI, Google Gemini, Anthropic Claude 모델 호출 분기 및 응답 처리
- 답안 분석·채점·첨삭용 시스템 프롬프트, 교사 페르소나 및 문체 파라미터 설계
- 활동자료와 학생 답안을 결합한 구조화 문맥 및 요약 캐시 구성
- 토큰 사용량과 모델별 예상 비용 기록, 월별 예산 상태 관리
- Google Vision `DOCUMENT_TEXT_DETECTION` 및 OpenAI 비전 OCR 연동
- OpenCV를 이용한 문서 외곽선 검출, 원근 보정, A4 비율 이미지 정규화
- OCR 원문·레이아웃·신뢰도·제공자·모델버전·검수상태 저장

### 정보보호·서비스 안정성

- 교사·학생 역할 및 승인상태 기반 접근통제
- 학생 중복 로그인 차단과 교체된 세션 강제 종료
- 운영환경 HTTPS 리다이렉트, Secure 쿠키, HSTS, CSRF 및 SameSite 정책
- 시험 대상 학생 검증, 업로드 MIME 유형 및 전송주기 제한
- Android 단말 내 미전송 감독 이미지의 Android Keystore 기반 AES-GCM 암호화
- 감독 이미지 저장공간 할당량·중단 임계치·보관기간·자동삭제 관리
- 감독 세션·이벤트·보안상태·기기진단 및 관리자 검토 기능
- 서명된 Android APK 배포, 앱 버전 검사 및 최소 지원 버전 강제

## 5. NCS 직무 관련성 검토

NCS는 산업현장에서 직무를 수행하는 데 필요한 지식·기술·태도를 국가가 체계화한 표준이다. Ingrid의 구현내용을 현재 NCS 분류와 비교하면 다음과 같이 판단할 수 있다.

| 신청 분야 | 관련 가능성이 높은 NCS 세분류·능력단위 | 프로젝트 근거 | 판단 |
|---|---|---|---|
| AI | `20.정보통신 > 01.정보기술 > 07.인공지능 > 05.인공지능서비스구현`의 구현요건분석, 상세설계, 애플리케이션 개발, 모델적용, 인터페이스 개발, 테스트, 자원구성, 안전성 검토 | 생성형 AI 다중 모델 연동, 프롬프트·페르소나 설계, OCR 파이프라인, 구조화 문맥, 사용량·비용 관리, 오류·재시도 및 검수 흐름 | **관련성 높음** |
| 정보보안 | `20.정보통신 > 01.정보기술 > 06.정보보호 > 01.정보보호관리·운영` 중 애플리케이션 보안 운영, 시스템 보안 운영, 보안성 검토 | 역할 기반 접근통제, 세션 통제, HTTPS/HSTS/CSRF, 암호화 임시저장, 저장공간·보관기간 관리, 보안상태 모니터링 | **관련성 있음(조건부)** |
| 정보보안 진단·사고대응 | 정보보호진단·분석, 보안사고분석대응 | 감독 이벤트와 보안상태 기록은 있으나 취약점 진단, 침해사고 분석·대응, 보안감사 수행을 입증하는 전용 산출물은 제한적 | **이 저장소만으로는 근거 부족** |

### 종합 판단

1. **AI 분야**: 인공지능 모델을 직접 학습시킨 프로젝트는 아니지만, 외부 AI 모델을 실제 교육 서비스에 적용하고 입력 문맥·프롬프트·인터페이스·결과 검수·비용·운영을 구현했다. 따라서 `인공지능서비스구현` 직무의 산업체 실무경력으로 설명할 근거가 충분하다.
2. **정보보안 분야**: 보안 기능을 실제 서비스에 설계·구현한 근거는 분명하다. 다만 안전한 웹 개발의 일부로 수행한 것인지, 정보보호를 주된 직무로 담당한 것인지가 심사에서 중요할 수 있다. 경력증명서에 보안 담당기간, 책임범위, 산출물과 운영업무를 구체적으로 적어야 한다.
3. **저장소만으로는 불충분**: GitHub는 구현내용과 기여 정황을 보여주는 보조자료다. 산업체와의 고용·계약 관계, 실제 수행기간 및 근무시간을 증명하는 공식 서류가 함께 필요하다.

4. **Git 기여내역**: 본인 GitHub 계정·이메일 확인자료, 기간별 커밋 목록, 주요 커밋과 변경파일
5. **서비스 운영자료**: 배포 화면, 운영 URL, 관리자 화면, 릴리스 기록, 장애·개선 이력 중 공개 가능한 자료

개인정보, API 키, 학생 답안, 감독 이미지 및 운영서버 비밀값은 증빙자료에서 반드시 제거한다.

## 9. 제출 전 확인사항

- 신청하려는 NCS 직종을 우선 `인공지능서비스구현`으로 검토하고, 정보보안은 실제 담당업무와 증빙 강도에 따라 추가 신청 여부를 판단한다.
- 최신 NCS 확인강사 신청 매뉴얼과 직종별 인정자격 매칭표를 고용24에서 다시 확인한다.
- 경력증명서의 담당업무가 단순히 “프로그램 개발”로만 적히지 않도록 AI 또는 보안 관련 실제 업무를 구체적으로 기재한다.
- Git 커밋기간과 공식 경력기간이 다를 경우 그 사유와 근거를 준비한다.
- 제출 전에 직업능력심사평가원 훈련과정심사센터(1644-5113)에 프로젝트형·자체개발·프리랜서 경력의 인정서류를 문의한다.
