# 감독 기록 다시보기 / MP4 다운로드

제출현황의 `기록 다시보기` 또는 실시간 감독 화면의 같은 버튼으로 진입한다.
진입 시 활동의 최근 기록일(기록이 없으면 오늘)을 기본 날짜로 표시한다.
날짜별로 전체 대상 학생의 썸네일 카드와 기록 장수를 표시한다.
기록 없는 학생은 `기록 없음`으로 표시하고 카드를 비활성화한다.
대상 목록에서 제외되었더라도 기존 기록이 있는 학생은 유지한다.
카드를 클릭하면 해당 학생의 기록만 조회하여 재생 모달을 연다.
재생, 일시정지, 1/2/4/8배속, 시간 슬라이더와 MP4 다운로드를 지원한다.
모달을 닫으면 재생/조회 요청을 중단하고 카드 목록 위치를 유지한다.
촬영 시각은 서버 수신 시각 기준이다.
촬영 공백에는 이전 화면을 유지한다. 3초 스냅숏은 실제 연속 녹화가 아니므로
그 사이 행동을 증명할 수 없다. 재생 화면과 원본 이미지 API는 담당 교사만 접근한다.

MP4는 다운로드 요청 시 FFmpeg로 생성하여 응답으로 스트리밍한다.
완성 MP4는 서버에 저장하지 않는다. 임시 파일은 이미지 경로 목록뿐이다.
한 서버에서 동시에 한 건만 변환하며, 영상 구간은 최대 4시간,
변환 실행은 최대 180초, 인코더는 1스레드로 제한한다.
다운로드를 취소하면 변환과 임시 목록을 정리한다.
MP4 자체에는 촬영시각 자막이 없으므로 정확한 시각 확인은 다시보기 UI를 사용한다.

## 배포 확인

- 서버에 FFmpeg와 libx264 인코더가 있어야 한다 (`ffmpeg -encoders`).
- PATH에 없다면 `PROCTOR_FFMPEG` 환경변수에 실행파일 절대경로를 설정한다.
- FFmpeg 미설치 시 다운로드 새 탭에 안내가 표시되며 다시보기는 정상 사용 가능하다.
- 프록시/Gunicorn 타임아웃을 확인한다. 최초 영상 응답 이전의 인코딩이
  타임아웃보다 길면 다운로드가 끊길 수 있다. 실제 서버에서 45분 기록을 검증한다.
- 프로덕션 이미지 저장소는 현재 로컬 FileField 경로를 사용해야 한다.
- 시험 중에는 다운로드보다 종료 후 검토를 권장한다. 이미지 저장 한도 차단은
  답안 API와 분리되어 있으며, 영상 변환도 서버 CPU를 사용한다.

## 수동 점검

1. 짧은 감독 기록을 저장하고 학생/날짜별 기록을 조회한다.
2. 재생, 배속, 슬라이더, 빈 기록 안내를 확인한다.
3. MP4를 받아 일반 동영상 플레이어에서 화면과 시간 흐름을 확인한다.
4. 다른 담당 교사나 학생 계정으로 기록/API 접근이 거부되는지 확인한다.
5. FFmpeg 미설치, 중복 다운로드, 다운로드 취소를 확인한다.
