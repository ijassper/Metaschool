# 감독 모드 변경 안내 — 선생님 전달용

> 아래 문구는 서버 변경과 새 인그리드 앱이 모두 배포된 뒤 안내합니다. 배포 전에는 현재 동작을 설명하는 문구로 사용하지 않습니다.

배포 담당자 확인: DB 마이그레이션 `0052`와 서버 코드를 함께 적용하고, 인그리드 앱 `0.3.17` APK를 업로드·검증한 뒤 서버의 최신/최소 지원 버전 설정을 올립니다. 수업 중 서버를 먼저 교체하면 기존에 열려 있던 답안 페이지는 새 캡처 토큰이 없어 감독 업로드가 중단되므로 수업 외 시간에 배포합니다.

선생님, 감독 모드의 화면 저장 방식을 개선했습니다. 학생이 답안을 **제출 완료**하면 인그리드 앱을 직접 종료하지 않고 태블릿 전원 버튼을 눌러 반납해도, 해당 응시의 화면은 서버에 더 이상 저장되지 않습니다.

답안을 제출하기 **전에** 화면을 잠그면 답안이 자동 제출되는 것은 아닙니다. 화면 녹화만 일시 중지되며, 학생이 다시 응시할 때 앱 화면의 **「녹화 다시 시작」**을 눌러야 합니다. 제출 후 수정이 허용된 활동은 학생이 답안 페이지에 다시 들어가면 새 감독 회차가 준비되고 녹화를 다시 시작할 수 있습니다.

선생님 화면에서는 **「제출 완료」**와 **녹화 상태**가 각각 표시됩니다. 제출한 학생의 카드에 사진이 남아 있어도 이는 마지막으로 받은 기록일 수 있습니다. 카드 위의 **「마지막 수신」** 시각을 확인해 주세요. 제출 여부의 최종 확인은 **「제출현황」**에서 해주시면 됩니다.

수업 종료 후에는 학생별 앱 종료를 지시할 필요가 없습니다. 다만 제출하지 않은 학생은 화면을 잠그더라도 **미제출 상태 그대로**이므로, 제출현황에서 확인해 주세요.
